Igreja São Francisco de Esperança - Website

Sobre o Projeto

Website institucional da Igreja São Francisco de Esperança, localizada em Barueri, SP. O site foi desenvolvido para promover a comunidade, divulgar eventos e facilitar o contato com os fiéis.

Como Usar

1.
Faça o download de todos os arquivos

2.
Mantenha a estrutura de pastas intacta

3.
Abra o arquivo index.html em um navegador

4.
O site funciona localmente sem necessidade de servidor

Personalização

Cores

As cores principais podem ser alteradas no arquivo style.css através das variáveis CSS:

CSS


:root {
  --primary-color: #00235f;
  --secondary-color: #ffd700;
  --accent-color: #e6c200;
  /* ... */
}


Conteúdo

•
Textos: Edite diretamente nos arquivos HTML

•
Imagens: Substitua os arquivos na pasta img/

•
Versículos: Edite o array em versiculo.js

•
Calendário: Edite as datas em script.js
